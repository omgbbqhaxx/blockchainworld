## What is BBlock?

BBlock is a single-component interlocking brick system designed for anyone who wants to build — without hiring a contractor, mixing mortar, or buying specialized tools.

You order the mold kit. You pour concrete at home. You stack the bricks dry.

That's it.

---

## How it works

1. **Order the 8-piece mold kit** — ships anywhere, one-time purchase for $99
2. **Pour concrete into the mold** — set time is ~1 hour per pour
3. **Pop out a perfectly shaped brick** — repeat hundreds of times with the same mold
4. **Stack dry, no mortar needed** — rotate 90° for perfect corners, no corner pieces required
5. **Reinforce if needed** — compatible with M22 steel rod reinforcement for structural builds

One shape handles everything: straight walls, corners, curves, enclosures.

## The product

The mold is 3D-printed from high-quality ABS plastic — flexible enough to demold easily, rigid enough to produce hundreds of identical bricks. Each brick interlocks with the next, creating a stable dry-stack wall that can be reinforced with steel rods for permanent structures.

**Kit contents:** 8-piece mold set  
**Price:** $99 (one-time)
